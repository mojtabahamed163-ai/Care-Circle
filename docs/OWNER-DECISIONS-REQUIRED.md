# معلومات مطلوبة من مالك المشروع قبل اعتماد سياسة الخصوصية والشروط

هذه القائمة تفصل الحقائق والقرارات غير الموجودة بشكل مؤكد في المستودع. لا ينبغي تخمينها أو تحويلها إلى وعود للمستخدمين.

| الموضوع          | السؤال المطلوب                                                                      | سبب الحاجة                                              |
| ---------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------- |
| الجهة القانونية  | ما الاسم القانوني والعنوان ووسيلة التواصل؟                                          | مطلوب لتحديد مسؤول البيانات والطرف المتعاقد.            |
| النطاق الجغرافي  | ما الدول أو الولايات المستهدفة؟                                                     | يحدد القوانين والحقوق المطلوبة.                         |
| الفئات العمرية   | هل الخدمة متاحة للقاصرين؟                                                           | يحدد متطلبات الموافقة والخصوصية.                        |
| مزودو الخدمة     | ما خدمات الاستضافة وقاعدة البيانات وتسجيل الدخول والتخزين؟ وأين تتم المعالجة؟       | لا يمكن استنتاج القائمة التشغيلية الكاملة من المستودع.  |
| الاحتفاظ         | ما مدد الاحتفاظ بالسجلات والحسابات والنسخ الاحتياطية وسجلات التشخيص؟                | التطبيق لا يحدد مدة قانونية نهائية.                     |
| النسخ الاحتياطية | هل توجد نسخ احتياطية إنتاجية؟ ومن يدير استعادتها؟                                   | النص الحالي لا يقدم وعدًا بالنسخ الاحتياطي.             |
| التشخيص          | هل جامع السجلات موجود في أي بيئة معاينة عامة؟ ومن يستطيع قراءة ملفات `.manus-logs`؟ | يحدد إفصاح التشخيص ومخاطر البيئة.                       |
| الحقوق           | ما آلية طلب الوصول والتصحيح والحذف والتصدير والاعتراض؟                              | مطلوبة لصياغة حقوق المستخدم.                            |
| الحوادث          | ما خطة الإخطار والتحقيق في حوادث الأمن؟                                             | لا توجد سياسة حادث مؤكدة في المستودع.                   |
| المحتوى          | من يملك محتوى الأسرة وما الترخيص اللازم لتشغيل الخدمة؟                              | مطلوب لشروط الاستخدام.                                  |
| إنهاء الحساب     | متى يمكن تعليق أو إنهاء الحساب؟ وكيف تُحفظ البيانات المشتركة؟                       | السلوك الحالي يغطي الحذف لكنه لا يحدد كل حالات الإنهاء. |
| التواصل          | إلى أين يرسل المستخدم شكاوى الخصوصية أو إساءة الاستخدام؟                            | يلزم نشر قناة واضحة.                                    |
| الإشعارات        | هل ستبقى عبارة عدم إرسال البريد أو Push صحيحة بعد انتهاء عمل الحساب الآخر؟          | نظام الإشعارات خارج نطاق هذا الفرع وقد يتغير.           |
| الامتثال         | ما الادعاءات القانونية أو الشهادات المسموح بها؟                                     | لا يجوز ادعاء HIPAA أو غيره دون إثبات ومراجعة مختصة.    |
| الإصدارات        | ما تاريخ النفاذ وسجل تغييرات السياسة؟                                               | مطلوب لإدارة النسخ القانونية.                           |

## المطلوب قبل النشر

1. تعبئة الإجابات من مالك المشروع والجهة التشغيلية.
2. مطابقة الإجابات مع سلوك بيئة الإنتاج، وليس المستودع فقط.
3. مراجعة المسودتين من مستشار قانوني مختص.
4. اعتماد النصوص وتاريخ نفاذها.
5. تنفيذ أي تغييرات تقنية لازمة لمطابقة السياسة المعتمدة.
